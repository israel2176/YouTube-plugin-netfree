# מעבר רציף ביוטיוב למשתמשי נטפרי

תוסף לכרום שמונע עצירה של הניגון ביוטיוב כשהסרטון הבא חסום בנטפרי.

## מה התוסף עושה

- בודק מראש אם הסרטון הבא חסום.
- אם כן – מחפש ביוטיוב סרטון פתוח לפי מילים מכותרת הסרטון הנוכחי, ומעביר אליו במקום הסרטון החסום.
- אם לא נמצא סרטון מתאים – עובר לסרטון אקראי מתוך רשימה קבועה.

הכול רץ בתוך הדפדפן מול youtube.com בלבד, ללא שרת חיצוני.

## התקנה

1. מורידים את קובץ ה־zip מהגרסה האחרונה בעמוד [Releases](../../releases/latest).
2. מחלצים את הקובץ לתיקייה.
3. נכנסים בכרום לכתובת `chrome://extensions`.
4. מפעילים את **מצב מפתח** (Developer mode) בפינה העליונה.
5. לוחצים על **טעינת תוסף לא ארוז** (Load unpacked) ובוחרים את התיקייה שחולצה.

## הגדרות

לחיצה על אייקון התוסף פותחת חלון שבו אפשר להוסיף מזהי סרטונים (ID בן 11 תווים) לרשימת הסרטונים האקראיים.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `content.js` | כל הלוגיקה של התוסף |
| `HTML/options.html`, `HTML/options.js` | חלון ההגדרות |
| `manifest.json` | הגדרות התוסף לכרום |

## הוצאת גרסה חדשה

מעדכנים את `version` בקובץ `manifest.json` וממזגים ל־`main`.
הגרסה תיבנה ותפורסם אוטומטית בעמוד Releases.
